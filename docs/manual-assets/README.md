# Manual artwork

These screenshots were captured from Voxel Demolition: Oblivion Protocol
0.2.2 on macOS during native release qualification on 10 October 2026.
They depict the same game in both former compiler profiles; there was no visual
or gameplay difference between those profiles.

Device metadata was removed before publication without re-encoding the JPEG
image scans. Their dimensions and decoded RGB pixels remain unchanged.

- `corporate-drop.jpg`: Corporate Drop with Event Horizon's precision setup.
- `neo-tokyo.jpg`: the procedural Neo Tokyo environment.
- `workbench.jpg`: Event Horizon's weapon workbench.

The screenshots and vector diagrams drawn by `scripts/build-manual.py` are
project-authored artwork, available under the project's MIT OR Apache-2.0
licenses. Interface content is generated by the game; the bundled font's MIT
notice is included in `THIRD_PARTY_NOTICES.md`.

The PDF uses these images for illustration. Its written reference is maintained
in `docs/manual.md`; screenshots may show an earlier interface/version label.
